# Image Editor

A browser-based image editor built with React, TypeScript, and Fabric.js.

The application allows users to upload an image and perform common editing operations including freehand drawing, adding shapes and text annotations, rotating, cropping, zooming, undo/redo, and exporting the edited canvas.

## Features

- Upload images
- Freehand drawing using Fabric.js Pencil Brush
- Add rectangles
- Add circles
- Add editable text annotations
- Rotate selected objects
- Crop images
- Undo and redo editing actions
- Zoom in and zoom out
- Export edited image as PNG
- Export canvas data as JSON
- Dark and light mode

## Tech Stack

- React
- TypeScript
- Fabric.js
- Vite
- CSS
